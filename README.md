# OutfitPOS Pro

Web/PWA kasir dan manajemen toko outfit yang bisa dijalankan dari HP.

Fitur: login admin, dashboard, POS, keranjang, pembayaran, stok, CRUD produk, riwayat transaksi, cetak struk, laporan 7 hari, kategori, backup/restore JSON, export CSV, pengaturan toko, ganti akun, responsive dan PWA.

Login awal: admin / admin123

Catatan: data tersimpan di localStorage perangkat. Untuk toko sungguhan multi-perangkat, gunakan backend/database.
